#
# A stack overflow is the one failure the CLR cannot turn into an exception, so nothing downstream
# could report it; JSC-79 records the day a conformance case terminated the process, JSC-85 records

# JSC-96 records that the arrangement which replaced it made stack exhaustion an abort no guest
# could catch - so `try { recurse(); } catch (e) { }`, which real programs write, never ran its own
